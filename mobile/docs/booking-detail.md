# Booking Detail View

The Booking Detail view displays saved itinerary details, passenger summaries, payment status, supplier reference policies, and cancellation terms for mobile users.

## Usage

```tsx
import BookingDetailScreen from '../screens/BookingDetailScreen';

// Render with itinerary, passenger, payment, and policy props
<BookingDetailScreen itinerary={...} passenger={...} paymentState="confirmed" supplierReferencePolicy={...} cancellationTerms={...} />
```
